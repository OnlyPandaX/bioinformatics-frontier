# Multi-Omics Daily Briefing Skill

> v1.4.0 | 每日多组学研究简报自动生成

搜索 Nature 和 ArXiv **当天**发表的论文，精选 3-5 篇高价值研究，生成结构化简报并推送到 GitHub。

---

## 核心流程

```
06:30 定时触发 → 搜索当天论文 → 关键词筛选 → 去重 → 生成简报 → 推送 GitHub → QQ 通知
                                  ↓
                            无相关论文 → 发送跳过通知
```

### 搜索策略（v1.4.0）

**仅搜索当天发表的论文**，不扩展到更早日期。

1. 搜索 Nature.com 当天发表的文章
2. 搜索 ArXiv q-bio.GN 当天提交的文章
3. 用关键词筛选相关论文
4. **当天无相关论文 → 不发简报**，用 message 工具发送跳过通知：「今日多组学简报：当天无新相关论文，跳过。」

### 去重机制

维护 `sent-papers.json` 已发送论文列表，避免重复推送。

- **每篇文章原则上只发送一次**
- 搜索范围仅当天后，去重主要防止跨源重复（同一论文在 Nature 和 ArXiv 同时出现）
- **重新发送需正当理由**：

| 理由 | 示例 |
|------|------|
| 后续进展 | 「因被 Nature 亮点报道有新进展」 |
| 被引用验证 | 「该研究被另一篇 Cell 文章引用和验证」 |
| 趋势汇总 | 「该方向连续发表 3 篇重要论文，值得汇总评述」 |
| 新数据集 | 「作者团队发布了配套大规模数据集」 |

去重列表路径：`sent-papers.json`（本 skill 目录下）

## 报告格式

### 必须包含

- 🏷️ **Skill 版本号**：报告末尾标注 `Generated by multi-omics-briefing v1.4.0`
  > ⚠️ 每次生成时**必须读取本 SKILL.md 获取当前版本号**，版本变更时自动跟随
- 📚 精选论文 3-5 篇
- 每篇论文：标题、作者、期刊/预印本、链接、概要、贡献、Critical 简评
- 📊 整体趋势评述

### 保存路径

**必须**按以下目录结构保存，**禁止**放在 `reports/` 根目录：

```
~/Documents/bioinformatics-frontier/reports/
└── YYYY/                    # 年份 (2026)
    └── MM/                  # 月份 (04)
        └── YYYY-Wxx/        # ISO 周 (2026-W17)
            └── YYYY-MM-DD-multiomics-briefing.md
```

- ✅ `reports/2026/04/2026-W17/2026-04-25-multiomics-briefing.md`
- ❌ `reports/2026-04-25-multiomics-briefing.md`（根目录，错误）

路径计算：`YYYY` = 年份，`MM` = 月份（补零），`Wxx` = ISO 周号（`date +%V`）
如目录不存在：`mkdir -p` 创建
