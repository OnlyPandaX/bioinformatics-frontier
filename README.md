## About / 关于

This repository collects daily curated research papers in multi-omics, genomics, transcriptomics, proteomics, metabolomics, and AI for biology.

本仓库收集每日精选的多组学、基因组学、转录组学、蛋白质组学、代谢组学以及AI在生物学中应用的前沿研究论文。

## Report Format / 内容格式

Each briefing includes / 每篇简报包含：
- 📚 3-5 curated papers / 精选论文
- Title, authors, journal/preprint, link / 标题、作者、期刊/预印本、链接
- One-sentence summary / 一句话概要
- Key contributions / 主要贡献
- Critical review (pros/cons, significance) / Critical 简评（优缺点、意义）
- 🔍 Overall trend commentary / 整体趋势评述
