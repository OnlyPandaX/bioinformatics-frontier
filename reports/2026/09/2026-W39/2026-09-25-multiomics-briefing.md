### 1. Motif-Vocab: 转录因子身份词元化——让基因组语言模型读懂 DNA 调控语法

| 字段 | 内容 |
|------|------|
| **标题** | Motif-Vocab: Statistically Calibrated Transcription-Factor-Identity Tokenization for Genomic Language Models |
| **作者** | Liangyu Li, Michael White |
| **平台** | arXiv (q-bio.GN) |
| **arXiv ID** | 2609.28386 |
| **发表日期** | 2026-09-23 |
| **链接** | https://arxiv.org/abs/2609.28386 |

**📝 一句话概要**  
Motif-Vocab 首次将转录因子（TF）结合位点的统计学显著性引入 DNA 分词（tokenization）过程，使基因组语言模型能直接"识别"调控元件而非被动处理序列字符。

**🔬 主要贡献**

- **生物信息学驱动的词元化**：利用位置权重矩阵（PWM）对双链 DNA 扫描，通过统计校准的零分布将不同长度/简并度的 TF motif 映射到统一显著性尺度，产生 TF-identity token，突破了传统 k-mer/BPE 分词忽略调控语义的局限。
- **大规模预训练验证**：在 20 亿碱基对上控制性 BERT 预训练显示，使用真实 motif 库在 55 项下游任务中 54 项优于随机 motif 对照。
- **可解释性证据**：TF-specific token 在注意力归因中更集中，遮挡实验效应更大，支持其生物学意义。
- **不替代通用模型**：结论审慎——Motif-Vocab 并非要取代通用分词器，而是为需要调控元件理解的任务提供了可插拔增强模块。

**💬 Critical 简评**  
> 这篇工作填补了基因组语言模型 tokenization 设计中的"生物学先验"空白。TF 结合位点作为最重要的顺式调控元件之一，长期被 NLP-in-bioinformatics 社区当作"另一个文本"来处理。Motif-Vocab 的核心贡献是将 PWM 的统计框架与深度学习 tokenization 优雅融合，使模型能在预训练阶段就建立对调控语法的基础认知。这对下游任务（如非编码区变异功能预测、增强子-启动子互作建模）有直接价值。95% CI 0.027–0.038 的 macro-F1 提升在 NLP 领域属于中等效果，但在调控基因组学中代表了一个可量化的突破。⚠️ 需要注意：文章尚在 AAAI-27 审稿中，方法学细节以最终发表版本为准。

### 2. CorrFlow: 空间组学生成——让基因共表达关系指导流匹配

| 字段 | 内容 |
|------|------|
| **标题** | Correlation-Guided Flow Matching with Annealed Masking for Spatial Transcriptomics Generation |
| **作者** | Yupei Zhang, Hao Chen, Li Pan, Chao Li, Xiaohan Xing |
| **平台** | arXiv (cs.LG/q-bio.GN) |
| **arXiv ID** | 2609.22187 |
| **发表日期** | 2026-08-28（cross-list 2026-09-22） |
| **链接** | https://arxiv.org/abs/2609.22187 |

**📝 一句话概要**  
CorrFlow 通过在流匹配框架中显式建模基因-基因共表达依赖，解决了从组织学图像预测空间转录组（ST）时忽略生物通路结构的核心问题。

**🔬 主要贡献**

- **基因间依赖建模**：引入退火掩码流匹配（annealed masked flow matching），基因子集按时间步长调度逐步解掩码，强制模型在预测某基因时考虑其他基因表达——这是对既往 ST 生成方法将基因视为独立预测目标的根本性改进。
- **双机制协同**：掩码机制 + 相关性引导双管齐下，使生成结果同时满足数值准确性和生物学一致性（保留共表达模式）。
- **对领域的影响**：空间转录组成本高、覆盖有限，从 H&E 图像预测 ST 是降本增效的重要路径，CorrFlow 使预测结果不再"看起来像 ST"而是"是生物学意义上的 ST"。

**💬 Critical 简评**  
> 流匹配（Flow Matching）已成为生成模型的主流范式，将其引入空间组学是一个自然且重要的进展。CorrFlow 的核心洞察——"基因不是独立变量"——在生物学上显而易见，但在方法学上长期被忽视。这篇文章的价值在于将通路/调控的生物学先验以计算可操作的方式编码进生成模型。从实用角度看，该方法若能泛化到多种组织类型的 H&E→ST 预测，将对空间解析转录组学的数据匮乏问题产生显著缓解。值得关注的是其退火调度设计——这是一个可以迁移到其他多模态生物数据生成任务的思想。

### 3. BreCol: 微生物组能否检测癌症？超大规模基准测试给出审慎答案

| 字段 | 内容 |
|------|------|
| **标题** | BreCol: Benchmarking Classical and Deep-Learning Methods for Microbiome-Based Cancer Detection |
| **作者** | Jeffrey M. Dick |
| **平台** | arXiv (q-bio.QM) |
| **arXiv ID** | 2609.27207 |
| **发表日期** | 2026-09-23 |
| **链接** | https://arxiv.org/abs/2609.27207 |

**📝 一句话概要**  
BreCol 汇集了 26 项研究、2,040 个 16S rRNA 测序样本，构建了肠道微生物组癌症检测的首个大规模时间分离基准，发现经典机器学习仍优于深度学习，并揭示了跨研究泛化性的关键瓶颈。

**🔬 主要贡献**

- **时间分离测试集设计**：训练数据来自 2023 年前研究，测试/留出评估来自 2023 年及之后——这一时序分离设计真实模拟了临床部署场景，有效避免了常见基准测试中的过拟合问题。
- **经典模型优势明显**：在留出测试集上，经典模型 AUC = 0.60（癌症诊断）/ 0.83（癌症分型），而 HyenaDNA 和 SetBERT 两种深度学习模型均低于经典方法。
- **新特征工程思路**：使用四聚体频率（tetramer frequency）的无监督聚类派生特征，无需依赖分类学注释即达到接近 SOTA 性能，提示组份内信号（within-run compositional signal）可能是微生物组生物标志物的关键。
- **结直肠 vs 乳腺癌**：前者更易检测，可能反映肠道微生物组与肿瘤的直接空间互作。

**💬 Critical 简评**  
> BreCol 是微生物组生物标志物领域难得一见的严格基准测试工作。时序分离设计直击该领域的核心痛点——实验室间、小组间的高变异性。深度学习在此任务中败给经典模型，并不令人意外：16S rRNA 数据本身维度相对有限（数百个 OTU/ASV），且微生物组数据的稀疏性、高噪声特性更适合基于距离/组成的传统方法而非端到端深度学习。更值得深思的是 tetramer 频率的发现——它绕过了分类学注释的不确定性，直接从序列组成层面提取信号，这可能为微生物组-肿瘤关联研究提供新的方法论思路。0.60 的留出 AUC 提示微生物组标志物距离临床癌症早筛尚有距离，但 0.83 的癌症分型能力展示了其作为辅助工具的潜力。
